## 1. NON-NEGOTIABLE TECHNICAL REQUIREMENTS

Build the project using:

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router for actual multi-page navigation
- Framer Motion or Motion for React for animations
- Lucide React for icons
- Three.js with React Three Fiber and Drei, if appropriate, for lightweight 3D scenes
- Recharts only if a chart is genuinely useful

Use modern, component-based TypeScript and Tailwind utility classes.

Do not build the project as plain HTML/CSS or a single static HTML file. Do not use JavaScript without TypeScript for the application components.

Custom CSS is allowed only where necessary for Tailwind configuration, keyframes, 3D effects, gradients, or advanced animations.

### Absolute restriction: frontend only

This is a STATIC FRONTEND PROJECT.

- No backend.
- No database.
- No server-side application.
- No authentication.
- No user accounts.
- No Firebase.
- No Supabase.
- No payment gateway integration.
- No API server.
- No secret API keys.
- No real payment verification.
- No server-dependent functionality.

Use local TypeScript data objects and client-side React state for content, forms, filters, calculators, pricing, and navigation.

The website must run using the normal Vite development server and be suitable for deployment as a static site.

Do not introduce a backend just to implement a feature.

Every visible button must perform a meaningful frontend action, navigate somewhere, open an appropriate modal, reveal information, or provide clear feedback. Do not leave decorative buttons that do nothing.
